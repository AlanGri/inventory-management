Factory Inventory Management

Vue 3 SPA on port 3000 calling a FastAPI service on port 8001 that serves in-memory JSON mock data. There is no database.

System architecture

Tech stack

Frontend

  • Vue 3.4, Composition API
  • Vite 8, @vitejs/plugin-vue
  • vue-router 4, axios 1.6
  • Custom SVG charts, CSS Grid

Backend

  • Python 3.11+, managed with uv
  • FastAPI 0.110+, Uvicorn
  • Pydantic 2 response models
  • pytest + TestClient in tests/backend

Data

  • 7 JSON files, loaded at startup
  • All filtering in memory per request
  • Read-only API (GET endpoints only)

Data flow

  1. FilterBar updates shared state in useFilters: time period, warehouse, category, order status.
  2. Views watch the filters and call api.js, which builds query params for http://localhost:8001/api.
  3. FastAPI runs apply_filters() over the in-memory lists and validates the output with Pydantic.
  4. Views store raw results in refs (allOrders, inventoryItems) and derive KPIs and charts with computed properties.

Worth knowing

  • Backlog.vue has no route; backlog data shows on the Dashboard via /api/backlog.
  • PurchaseOrder and CreatePurchaseOrderRequest models exist, but there's no POST endpoint yet. That matters for the Restocking feature in Step 6.
  • The API base URL is hardcoded in api.js.
